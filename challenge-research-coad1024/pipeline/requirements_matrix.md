# Research Requirements Matrix

| ID | Requirement | Description | Validation Method |
| :--- | :--- | :--- | :--- |
| **REQ-01** | **Topic Selection** | Must be one of: Oracles, Stablecoins, Bridges, Privacy. | Check Title |
| **REQ-02** | **Analysis Section** | Compare 2-3 relevant assets/protocols. | Count Items |
| **REQ-03** | **Analysis Dimensions** | Must compare: Security, Sustainability, Decentralization (and topic-specifics). | Check Headers |
| **REQ-04** | **Design Section** | Must address 2 specific scenarios (Ideal/Free Gas vs. Constrained/Risky). | Check Scenarios |
| **REQ-05** | **Modelling Section** | Model economic feasibility (Cost vs. Profit) of an attack. | Check Math/Logic |
| **REQ-06** | **Diagrams** | Must include diagrams to explain concepts/flows. | Check for Mermaid |
| **REQ-07** | **Conciseness** | Keep it focused; no fluff. | Word Count / Review |
